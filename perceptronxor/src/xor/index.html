Laboratório MLP XOR

Uma experiência interativa para acompanhar a aprendizagem por retropropagação (backpropagation) e a inferência de uma rede neural 2 → 4 → 1, neurônio por neurônio.

Ir para: Arquitetura · Inferência · Treinamento · Roteiro passo a passo · Evolução

1. Configure a experiência

A demonstração usa quatro exemplos XOR, ativação sigmoide e perda quadrática média (MSE), seguindo a lógica do script Julia. Os parâmetros do navegador são independentes do arquivo .jls salvo pelo Julia. O treinamento é em lote: os gradientes dos quatro exemplos são calculados antes de atualizar os parâmetros.

Inicialize ou treine a rede para começar.

2. Arquitetura da rede

Entradas

x = [x₁, x₂]

Os valores binários entram na rede sem ativação adicional.

Camada oculta

z₁ = x · W₁ + b₁
a₁ = σ(z₁)

Cada um dos quatro neurônios calcula sua própria soma ponderada e aplica a sigmoide.

Camada de saída

z₂ = a₁ · W₂ + b₂
ŷ = σ(z₂)

A saída é interpretada como probabilidade estimada da classe 1.

4. Treinamento: uma época por dentro

Em cada época, a rede percorre os quatro exemplos. Primeiro calcula a propagação direta; depois mede a perda; em seguida calcula os deltas e atualiza os parâmetros.

Perda quadrática média

L = (1/n) Σ (y − ŷ)²

Delta de saída

δ₂ = (ŷ − y) · ŷ · (1 − ŷ)

Delta oculto

Etapa 1 de 5

1. Propagação direta

A rede calcula uma previsão para cada uma das quatro entradas XOR usando os mesmos pesos iniciais.

O que é uma época?

Uma época corresponde a uma passagem de treinamento sobre os quatro exemplos: (0,0), (0,1), (1,0) e (1,1). Nesta implementação, os gradientes são agregados e os parâmetros são atualizados ao final do lote.

O que muda?

Os pesos controlam a influência de cada entrada; os vieses deslocam a soma ponderada. O gradiente descendente ajusta ambos para tentar reduzir a perda.

7. Entenda cada fórmula

Propagação direta

zⱼ = Σᵢ xᵢwᵢⱼ + bⱼ
σ(z) = 1 / (1 + e⁻ᶻ)

A soma ponderada agrega os sinais de entrada; a sigmoide comprime o resultado para o intervalo (0, 1).

Perda

L = (1/n) Σ (y − ŷ)²

Compara a saída estimada com o alvo. Quanto menor a perda, mais próximas estão as previsões dos valores desejados.

Retropropagação

σ′(a) = a(1 − a)

Os deltas estimam como a perda varia em relação às somas ponderadas dos neurônios.

Atualização

w ← w − η · ∂L/∂w
b ← b − η · ∂L/∂b

O gradiente descendente altera pesos e vieses na direção que reduz a perda, com tamanho de passo controlado por η.
